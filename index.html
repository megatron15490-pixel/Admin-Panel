About this prototype

Version 0.1.0 · Browser demo

Securly 2.0 is a learning prototype inspired by school device-management consoles.

Data is stored in this browser using localStorage. Clearing browser site data may erase it. Device status and policy decisions are simulated and are not connected to school systems.
